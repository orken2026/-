# 🚘 QAZAQ PDD — Telegram бот + Mini App (ақылы нұсқамен)

Қазақстандағы B, C1, C санаттарына арналған ЖЖҚ (ПДД) емтихан тренажері. Қазақша және орысша.

- **260 сұрақ** (200 жалпы + 60 жүк көлігі), 91 суретті сұрақ — әрқайсысының өз суреті бар.
- Әр сұраққа түсіндірме және **ЖЖҚ тармағына сілтеме** (ҚР ІІМ 30.06.2023 №534 бұйрығы).
- Емтихан: 40 сұрақ / 40 минут / өту шегі 32. Режимдер: тақырыптар, қателермен жұмыс, марафон, бетбелгілер.
- Жол белгілері анықтамалығы, куәлік алу кезеңдері, күнделікті сұрақ (бот quiz), «Неге?» AI түсіндірмесі.
- Төлем: **Telegram Stars** (әдепкі 50 ⭐ ≈ 500 ₸, біржолғы). Тегін нұсқада 58 сұрақ ашық.

## Архитектура

| Бөлік | Адрес | Не істейді |
|---|---|---|
| Mini App | https://qazaq-pdd-app.onrender.com | Интерфейс. Жауаптар **жоқ** — тек API-ден алады |
| Бот + API | https://qazaq-pdd-bot.onrender.com | Сұрақтар базасы, жауап тексеру, төлем, бот командалары |
| Күйі | https://qazaq-pdd-bot.onrender.com/status | Бот, webhook, мәзір, төлемдердің қалпына келуі |

Қауіпсіздік: дұрыс жауаптар тек серверде (`data/questions.json`, ол сайтқа шықпайды). Әр емтихан/жаттығу
қол қойылған токенмен беріледі, нұсқалар әр жолы араласады. Пайдаланушы Telegram `initData` (HMAC) арқылы танылады.

Деректер: серверде тек Telegram ID, тіл, төлем жазбалары. Оқу прогресі Telegram CloudStorage-та. Аты-жөні, телефон жиналмайды.
Төлемдер база өшсе де жоғалмайды — сервер іске қосылғанда Telegram-нан (`getStarTransactions`) қалпына келтіреді.

## Баптау (Render → qazaq-pdd-bot → Environment)

| Айнымалы | Міндетті | Мәні |
|---|---|---|
| `BOT_TOKEN` | иә | @BotFather токені. Ешқайда (чат, код, GitHub) жазбаңыз |
| `ADMIN_IDS` | ұсынылады | Сіздің Telegram ID (білу: @userinfobot). Тегін толық қолжетімділік, `/stats`, `/refund` |
| `SUPPORT` | ұсынылады | Төлем бойынша байланыс: `@username` немесе телефон (`/paysupport` көрсетеді) |
| `PRICE_STARS` | жоқ | Баға (әдепкі 50) |
| `PLAN_DAYS` | жоқ | 0 — мерзімсіз; мысалы 30 — бір айға |
| `ANTHROPIC_API_KEY` | жоқ | «Неге?» AI түсіндірмесі (тек төлегендерге, күніне 30 рет) |
| `DATA_DIR` | жоқ | Тұрақты база папкасы (VPS/диск). Бос болса — база жадта |
| `DAILY_HOUR` / `DAILY=0` | жоқ | Күн сұрағы сағаты (Алматы, әдепкі 19) / өшіру |

Маңызды: Render-де `git push` автоматты deploy жасамайды — Render панелінде **Manual Deploy** басыңыз.

## Тегін Render тарифінің шектеулері

- Бот сервері 15 минут қолданылмаса ұйықтайды: алғашқы ашылу 30–60 секунд (Mini App «Сервер оянып жатыр» деп көрсетеді).
- База жадта: қайта іске қосылғанда «күн сұрағы» жазылымдары өшеді (төлемдер қалпына келеді).
- Күн сұрағы сервер ояу кезде ғана жіберіледі.

Тұрақты жұмыс үшін: Render **Starter** + Disk (`DATA_DIR=/var/data`) немесе **ҚР аумағындағы VPS** (дербес деректерді
оқшаулау талабы үшін ұсынылады) — `Dockerfile` дайын:

```bash
docker build -t qazaq-pdd .
docker run -d --restart=always -p 8000:8000 -v qazaq_pdd_data:/data \
  -e BOT_TOKEN=... -e PUBLIC_URL=https://bot.example.kz -e MINI_APP_URL=https://bot.example.kz \
  -e ADMIN_IDS=... -e SUPPORT=@... qazaq-pdd
```

(HTTPS үшін алдына Caddy/Nginx. Бұл жағдайда Mini App сол сервердің өзінен ашылады.)

## Сұрақтар базасы

```
content/schema.py      тақырыптар және Q(...) пішімі
content/bank_g*.py     жалпы сұрақтар (g001–g200), bank_c.py — жүк көлігі (c001–c060)
content/build_bank.py  тексеру → data/questions.json;  --xlsx → маманға арналған Excel
```

Әр сұрақ: `Q('g201', 'signs', False, '2.5', 'қаз мәтін', ['ДҰРЫС', 'қате', 'қате', 'қате'], 'қаз түсіндірме', 'рус текст', [...], 'рус пояснение')`.
Дұрыс жауап әрқашан бірінші жазылады (көрсеткенде араласады). Сілтеме: `'24.5'` — 24-тармақ 5)-тармақша, `'z2.5'` — белгі, `'m1.1'` — таңба.

```bash
python3 content/build_bank.py            # data/questions.json жаңарту
python3 content/build_bank.py --xlsx     # Qazaq_PDD_suraqtar_tekseru.xlsx — автомектеп нұсқаушысына тексертуге
```

## Суреттер

`tools/art/scenes.py` — әр суретті сұрақтың сахнасы, `tools/art/signs.py` — анықтамалық белгілері (тек стандартты Python).
`python3 tools/art/build.py` → `webapp/assets/q-*.svg`, `python3 tools/art/signs.py` → `webapp/assets/signs/*.svg`.

## Тесттер

```bash
python3 tests/server_test.py     # жалған Telegram API: авторизация, төлем, бағалау, жауаптардың жабықтығы, webhook
node tests/webapp_check.cjs      # Mini App: синтаксис, қаз/рус мәтіндер, суреттер, клиентте жауап жоқтығы
```

Жергілікті көру: `DEV_AUTH=1 python3 server.py` → `http://localhost:8000/?dev=1` (өндірісте `DEV_AUTH` ҚОСПАҢЫЗ).

## Құқықтық ескерту

Бұл — оқу тренажері, ресми спецЦОН жүйесі емес. Сұрақтар ЖЖҚ негізінде авторлық түрде құрастырылған; сатудан бұрын
автомектеп нұсқаушысына тексертіңіз (Excel парағы). Жария оферта мен құпиялылық саясатын заңгермен келісіңіз.
